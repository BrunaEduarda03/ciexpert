# ROBOT

## how to run?

```sh
cd sim
make robot_comp    # → compila
make robot_sim     # → roda simulação batch
make robot_gui     # → abre simulação interativa na GUI
make robot_wav     # → abre verdi com ultima interacao da GUI
make robot_verdi   # → abre verdi + waveforms + ultima simulacao
make robot_restart # → compila e simulacao
```
